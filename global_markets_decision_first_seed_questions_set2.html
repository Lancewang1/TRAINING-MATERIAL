Design pattern used in this set

The strongest examples here are deliberately not “retrieve X and calculate Y.” The agent first has to decide which contractual or market state applies, using evidence that can be independently checked. The calculation then substantiates that judgment.

terms / convention → historical evidence → classify the state → apply the correct branch/formula → answer with a verifiable judgment

This preserves the feature you liked in the daily knock-in and CMS-steepener examples: the task involves interpretation and judgment, but the judgment has ground truth once the contract and market evidence are fixed.

Was the rate inside the contractual accrual region often enough to produce a full, partial, or zero coupon for the selected quarter?

SEED QUESTION

EXPECTED ANSWER

Classification + accrual-day count + coupon rate + dollar payment

  5. Count N and ACT; determine whether the result is full, partial, or zero accrual.
